# AI 생애소통 서비스 — 사업 기획안 v7
*2026.05 — PoC 개발 병행 버전*

---

## 1. 사업 정의

**AI 대화 에이전트가 요양시설 어르신의 생애 이야기를 듣고, 구조화하고, 가족에게 전달하는 '생애소통' 서비스.** 현장 보조 진행자는 세팅과 안전 대응만 담당한다.

**서비스명 — "생애소통":**
"회상치료(Reminiscence Therapy)"는 임상적 방법론이지 서비스 정체성이 아니다. 서비스가 실제로 하는 일은 AI가 어르신의 생애 이야기를 경청하고, 구조화하고, 가족에게 전달하는 것이다.

**이중 메시지 구조:**

| 대상 | 메시지 |
|------|--------|
| 시설 원장 | "입소자에게 생애 이야기로 정서 관리 서비스를 제공하고, 보호자에게 세션 종료마다 그 내용을 요약해서 전달하는 가족 소통 프로그램입니다. 입소자와 보호자 모두의 만족도를 높이고, 기관평가 프로그램 운영 근거를 생성하고, 직원 업무량 증가를 최소화합니다." |
| 투자자 | "요양시설 SaaS로 반복적이고 합법적인 인간 생애 구술 데이터 수집 채널을 확보합니다. 보호자 앱은 가족 검증 인터페이스입니다. 핵심 자산은 동의 기반 고령자 감정 대화 데이터셋입니다." |

**같은 제품, 다른 언어.** 요양시설 원장과 프로젝트 투자자에게 전달할 내용이 구분된다.

**사업 구조:**

| 레이어 | 정의 |
|--------|------|
| 프론트 매출 | B2B 시설 SaaS 구독 |
| 인게이지먼트 | 보호자 무료 알림 + 유료 보존 상품 (매출보다 retention·데이터 검증) |
| 핵심 자산 | 동의 기반 감정 대화 데이터셋 |
| 장기 수익 | 데이터 라이선싱 + 벤치마크/평가 API |

**데이터가 Moat인 5가지 조건:**

| 조건 | 설계 |
|------|------|
| 채널 해자 | 요양시설 계약으로 반복 데이터 수집 채널 확보 — 크롤링 불가 |
| 동의 해자 | 서비스 시작부터 L1~L6 상업적·연구적 활용 권리 확보 |
| 구조화 해자 | 매 세션 자동으로 주제·감정·인물·시간축·위험도 메타데이터 부착 |
| 검증 해자 | 보호자 반응(사실 정정·인물 보완·감정 신호)이 데이터 품질을 높이는 피드백 루프 |
| 윤리 해자 | 적법한 동의·철회권·비식별·민감정보 프로토콜 — 이 절차 자체가 후발주자의 진입장벽 |

## 2. 왜 지금인가

**수요:** 2025년 초고령사회 진입. 장기요양 인정자 110만 명(2024 기준)[^1]. 노인의료복지시설 6,195곳(2024.12 기준)[^2]. 베이비부머(1955~63, 약 700만)가 2026년부터 본격 요양시장 진입 — 디지털 친화적 자녀를 둔 세대. 인지 정상 입소자 40~50%에게 제공할 콘텐츠 부재.

**시장 규모:** 장기요양보험 급여비 2024년 14.5조원(전년비 15.3% 증가)[^3]. 고령친화산업 전체 약 84.9조원(2022)[^4]. 시설 급여(입소 시설 관련)는 전체 급여비의 약 40% — 요양시설에 직접 흐르는 돈만 연간 5~6조원 규모.

**기술 임계점:** LLM 대화 품질 2024년 돌파. 한국 AI 기본법 2026.01.22 시행[^5]. JMIR Aging (2026.04) AI 기반 생애 이야기 구조화 기술적 타당성 학술 검증 시작[^6].

**임상 근거:** 인간 진행 회상치료 우울 감소 효과크기 g=1.41 (Pinquart & Forstmeier 2023, 42개 RCT 3,361명)[^7]. **단, AI 진행 효과는 PoC에서 GDS로 별도 검증 필요.**

**경쟁 시간 압박:** 동국대 컨소시엄 과기부 16.77억(2026.04~2028.12)[^8]. 딥브레인AI 리메모리(2024 매출 71.6억)[^9]. KB·신한 보험사 자체 개발 검토. **18~24개월 내 시장 표준 사업자 결정 가능성.**

## 3. B2B 매출 — 원장이 왜 다음 달에도 돈을 내는가

**이 사업의 1순위 증명 과제.** 데이터 해자도, 보호자 앱도, 보험사 LOI도 아닌, 요양시설 원장이 자기 돈으로 다음 달에도 쓰겠다고 해야 비로소 의미가 있다.

### 원장 관점 가치

원장은 데이터 전략이나 AI 기술에 관심이 없다. 원장이 매일 마주하는 문제는: 보호자 민원, 기관평가, 입소 상담 차별화, 직원 이직. 생애소통은 이 네 가지에 직접 답해야 한다.

| 원장의 질문 | 우리의 답 |
|-------------|----------|
| 보호자 민원이 줄어드나? | 세션 종료 후 보호자에게 세션 리포트 자동 발송 → 보호자가 '우리 엄마 오늘 뭐 했는지 인지' → 만족도 상승 |
| 기관평가에 도움 되나? | 장기요양기관 평가의 '급여제공과정' 영역에 여가활동·인지자극 프로그램 운영 관련 평가지표가 포함됨[^10]. 생애소통 세션은 프로그램 계획·실행·기록을 자동 생성하여 **평가 근거 자료로 활용 가능**. 단, 구체적 인정 범위는 평가매뉴얼 확인 및 파일럿 시 평가 컨설턴트 검증 필요 |
| 입소 상담 차별화가 되나? | "저희 시설은 AI로 부모님의 생애 이야기를 기록하고 가족에게 매주 전달합니다" — 상담 자료로 즉시 활용 |
| 직원 업무가 늘어나나? | 보조 진행자 1명 × 세션 20~25분. AI가 인터뷰·기록·리포트 전부 자동 처리. 기존 수작업 프로그램보다 인력 부담 적음 |
| 몇 명한테 적용 가능한가? | 시설 30명 기준 목표 참여율 60%(18명). 보호자 연락처 확보율 70% 가정 시 13가구에 알림 발송. **PoC에서 실측 검증 필요** |
| 사고 나면 책임은? | 3단계 안전 프로토콜(경미→중간→위기). 위기 시 AI 즉시 중단 + 시설 즉시 알림. 민감정보 자동 필터링 |

### 운영부하 KPI

시설이 "업무가 늘어난다"고 느끼면 재계약 없다. 세션 운영 전체 소요시간(세팅+세션+정리)을 정량 관리.

| 지표 | 목표 | 산식/기준 |
|------|------|----------|
| 세션 1회당 총 운영시간 (세팅+세션+정리) | ≤ 35분 | 세팅 5분 + 세션 20~25분 + 정리 5분 |
| 참여 노인 1명당 월 총 운영시간 | ≤ 140분 | 주 1회 × 35분 × 4주 (상용 Standard 기준) |
| 시설 30명(참여 18명) 기준 보조 진행자 월 투입시간 | ≤ 42시간 | 18명 × 월 4회 × 35분. 하루 3~4시간, 주 5일 |
| 수동 검수율 (리포트 자동생성 중 수동 개입) | ≤ 20% | 시스템 로그 |

*상용은 주 1회 기본 / 주 2회 Premium. PoC에서는 데이터 밀도 확보를 위해 주 2회로 운영하되, 상용 전환 시 주 1회가 원장 수용성 높음. 35분을 넘기면 기존 수작업 프로그램 대비 우위가 사라짐.*

### 가격 구조

A안/B안 양안 준비. PoC에서 원장 WTP 검증 후 결정.

| | A안 (자립형) | B안 (침투형) |
|--|-------------|-------------|
| 시설당 월가 | 80~150만원 | 40~70만원 |
| 목적 | B2B 단독 손익분기 지향 | 시설 수 빠른 확보, 데이터 채널 조기 확보 |
| 실체 | SaaS 사업 | **데이터 확보용 침투 전략. 시설당 공헌이익 ≈ 0** |

*노인 1인당 월 변동 원가 2.3~3.7만원. 30인 시설(참여 18명) 기준 원가 41~67만원. B안 하한 40만원이면 원가와 동일 — SaaS가 아니라 데이터 매입비.*

*외부 영업 시에는 Pilot(30~50만원, 8~12주) → Standard(~90만원) → Premium(150만원+) 패키징으로 전환 예정.*

## 4. 보호자 레이어 — retention + 데이터 검증

**초기 3년간 보호자에게서 돈 받는 것은 주 목표가 아니다.** 보호자 레이어의 역할: (1) 시설 재계약 근거, (2) 데이터 품질 향상.

### 무료 알림 (키즈노트 모델)

키즈노트[^11] 사례가 벤치마크. MAU 236만, 매출 245억이지만 보호자 직접 과금 0원 — 수익은 광고·커머스·프리미엄 B2B. 알림 자체는 무료. 재생산 가능한 것(요약, 이미지, 클립, 다이제스트) = 무료. 유일하고 편집된 것(전체 스토리, 영상, 자서전) = 유료.

### 보호자 = Human Validation Layer

이 서비스의 진짜 차별점은 "AI가 노인 이야기를 듣는다"보다 **"노인 발화 + 가족 검증 + 감정 반응이 하나의 데이터셋으로 연결된다"**에 있다.

| 보호자 행동 | 데이터 가치 |
|------------|-----------|
| "이분은 큰아버지예요" | 인물 관계 그래프 보정 |
| "대구가 아니라 부산이에요" | 사실 검증 |
| "이 이야기 더 듣고 싶어요" | 감정 가치 신호 |
| "이 내용은 공유하지 말아주세요" | 민감도 라벨링 |

**보호자 앱 KPI:** 열람률, 정정률, 댓글률, 공유율, 저장율, "더 듣고 싶은 주제" 선택률.

### 유료 상품 (보조 매출)

생신/어버이날 특별 영상(5~10만원, 이벤트 트리거), 3개월 소책자(5만원), 전체 스토리 구독(월 1~2만원), 자서전(30~50만원, 6개월+ 누적 후).

### 광고·커머스 (Y3+ 부가 옵션)

보호자 앱 MAU가 수천+ 도달 시 시니어 관련 브랜드 광고, 효도 선물 커머스 연동 가능. 단, Y5 B안 200곳 기준에서도 MAU ~2,600가구 수준으로 대규모 광고 매출은 비현실적. **핵심 수익이 아닌 부가 옵션으로 위치.**

## 5. 핵심 자산: 동의 기반 고령자 감정 대화 데이터셋

**이 섹션이 사업의 알파이자 오메가.**

### 5-1. 데이터 정의 & Dataset Card

6개 레이어가 결합된 복합 데이터셋: 음성(원음성+발화속도·침묵·웃음·울먹임) / 텍스트(STT+AI 질문) / 메타데이터(주제·감정·인물·장소·시간축·회상깊이·민감도) / 상호작용 패턴(질문→반응→후속→지속/이탈) / 보호자 반응(열람·정정·저장·공유) / 종단 데이터(동일 고령자 다회 세션).

**상품명:** **"고령자 장기 감정 상호작용 데이터셋 (Korean Elderly Emotional Interaction Dataset)"**

| 항목 | 내용 |
|------|------|
| 대상 | 70~95세 요양시설 입소자, 인지 정상~MCI |
| 수집 방식 | AI 주도 생애소통 세션 (회상치료 방법론 기반) |
| 모달리티 | 음성, 전사 텍스트, AI 질문, 메타데이터, 보호자 반응 |
| 평균 세션 | 20~25분 |
| 라벨 | 주제, 감정, 인물, 장소, 시간축, 민감도, 회상 깊이 |
| 검증 | 보호자 Human Validation |
| 동의 | L1~L6 독립 opt-in, 언제든 철회 가능 |
| 제외 사용처 | 보험 심사, 개인 프로파일링, 광고 타깃팅, 재식별 |
| 제공 방식 | 제한형 라이선스, 연구용 샘플, 벤치마크/API |

### 5-2. 왜 희소한가

인터넷에 없다. 크롤링·합성 불가. (1) 채널 장벽: 시설+고령자+보호자 동의 동시 필요, (2) 시간 장벽: 수십 회 연속 세션에서만 나오는 깊이, (3) 소멸 장벽: 고령자 인지 저하·사망으로 원천 소멸, (4) 윤리 장벽: 적법 동의 없이 상업적 활용 불가.

### 5-3. 데이터 가치 산정 — 판매 가능 데이터 기준

"총 축적 × 단가"는 비현실적. License-Ready 데이터만 의미 있다.

**Y3(시설 40곳) 기준:**

| 단계 | 산식 | 결과 |
|------|------|------|
| 총 축적 데이터 | 40곳 × 18명 × 주 1.5회(평균) × 52주 × 25분 | ~23,400시간/연 |
| L6 동의 확보 | × 50~70% | 11,700~16,380시간 |
| STT usable | × 85% | 9,945~13,923시간 |
| 비식별 처리 후 사용 가능 | × 80% | 7,956~11,138시간 |
| 라벨 품질 검수 통과 | × 60~70% | 4,774~7,797시간 |
| **License-Ready** | **최종** | **약 5,000~8,000시간** |

**핵심 KPI — License-Ready Data Ratio:** 전체 수집 중 라이선싱 가능 비율. Go 기준 35%+, Stretch 50%+.

> **산식:** License-Ready Ratio = L6 동의율 × STT usable률 × 비식별 후 사용가능률 × 라벨 품질 검수 통과율

### 5-4. 수요자 우선순위

가까운 순서. 먼 미래의 구매자로 현재를 정당화하면 안 된다.

| 순위 | 구매자 | 필요한 이유 | 시점 |
|------|--------|-----------|------|
| 1 | 연구기관 | 고령자 대화 데이터 희소. 논문·GDS 연구 | Y1~Y2 |
| 2 | STT/음성 AI | 고령자 한국어 음성 인식 개선 | Y2~Y3 |
| 3 | 대화 AI/LLM | 고령자 대화 패턴 학습 | Y2~Y3 |
| 4 | 감정 AI | 공감 AI 학습 데이터 | Y3+ |
| 5 | 돌봄 AI/케어봇 | 장기 관계·민감 주제 대응 | Y3~Y4 |
| 6 | 보험사 | 집계 통계·프로그램 효과 리포트 (**raw data 아님**) | Y3+ |
| 7 | 휴머노이드 | 고령자 대상 감정 소통 학습 | Y5+ |

*7번 휴머노이드에 대해: 단순 요양시설 배치용에 국한되지 않는다. 궁극적으로 휴머노이드가 모든 연령대에 보급되려면 고령자를 포함한 전 세대와의 자유로운 감정 소통이 전제 조건이다. 고령자 감정 대화 데이터는 그 퍼즐의 한 조각이며, 현재는 가능성이 희박하지만 범주 자체를 제한하지 않는다.*

### 5-5. 첫 데이터 라이선싱 계약 시나리오

**시나리오 1 — STT 회사 (가장 가까운 유료 구매자):**
L6 동의 + 비식별 고령자 음성 300시간 + 정답 전사. 1년 제한 라이선스. 3,000만~1억원. 재판매·재식별·보험/마케팅 활용 금지.

**시나리오 2 — 대학 연구팀:**
비식별 transcript + 감정/주제 라벨. 공동 연구 + 논문 공동 저자. 현금은 작지만 학술 검증이 시장 인지를 만든다.

**시나리오 3 — 돌봄 AI 스타트업 (벤치마크/API):**
raw data가 아니라 고령자 대화 AI 품질 평가 벤치마크. 평가 API 월정액 300~1,000만원. "이 벤치마크를 통과하지 않으면 고령자 대응 품질을 증명할 수 없다" 포지션.

### 5-6. 수익화 경로

| Phase | 시기 | 활동 |
|-------|------|------|
| 1 | Y1~Y2 | 내부 모델 개선 + 학술 논문 공동 발표 (매출 0, 신뢰 구축) |
| 2 | Y2~Y3 | 연구기관·STT 제한형 라이선싱 (건당 계약) |
| 3 | Y3~Y4 | 구매자별 맞춤 데이터 상품 (본격 매출) |
| 4 | Y4+ | **고령자 대화 AI 벤치마크/평가 API — 궁극 목표** |

**Phase 4가 핵심:** 데이터 단순 판매가 아니라 고령자 대화 AI 품질 평가의 표준 인프라. 1회성 판매 vs 반복 매출.

### 5-7. 데이터 권리 설계

**6단계 동의 (각 레벨 독립 opt-in):**
L1(세션 참여·녹음) → L2(가족 전달) → L3(유료 상품화) → L4(사후 열람) → L5(비식별 연구·품질 개선) → **L6(비식별 외부 라이선싱 — 핵심 KPI)**

**L6 동의율별 전략 분기:**
- 70%+ → 데이터 사업 본격 추진
- 40~70% → 데이터 사업 축소, B2B SaaS 중심
- 40% 미만 → 순수 SaaS 피벗

**L6 동의 문구 (법무 검토 전 초안 — 실제 동의서 문구는 개인정보보호 전문 변호사 검토 후 확정):**
> "개인을 식별할 수 없도록 처리된 데이터는 고령자 돌봄 AI 품질 개선, 학술 연구, 음성·대화 AI 성능 평가 목적으로 외부 연구기관 또는 기업에 제한적으로 제공될 수 있습니다. 보험 심사·개인 평가·광고 타깃팅에는 사용 불가하며, 동의는 언제든 철회 가능합니다(24h 접근 차단, 7일 내 삭제)."

**프롬프트 v8.1 설계 완료** (503줄). 7개 주제 트리 × 4단계 깊이, 감각 앵커링, 인지수준 적응, 3단계 안전 프로토콜. **세션 기록 프롬프트 v2 완료** — 구조화 JSON 자동 생성.

**세션 깊이 변화 예시:**
```
1회차: 단답 중심. "네", "글쎄요". 발화 평균 10초.
3회차: 특정 인물 반복 등장. "우리 아버지가..."

```
*이 깊이 변화가 종단 데이터의 핵심 가치이며, 단발 인터뷰로는 절대 얻을 수 없는 것.*

## 8. 시장 환경 & 경쟁

### 8-1. 국내 시장

**프로그램 공백:** 기관평가에서 여가·인지자극 프로그램 운영 지표를 충족해야 하지만[^10], 대부분의 시설은 수작업 레크리에이션(체조, 노래, 종이 활동지), 외부 강사, TV 시청에 의존. 디지털 인지자극 프로그램은 시장 초기 단계. 일본에서 TOPPAN이 AI 레크리에이션 SaaS를 2024년 출시한 것과 대비하면[^17], 한국에는 이 포지션 자체가 비어있다.

**보호자 커뮤니케이션 공백:** 케어포(14,000+ 기관)[^12], 또하나의가족 등은 전부 행정 알림(혈압, 식단, 투약). **감정·서사 콘텐츠를 보호자에게 전달하는 서비스는 국내에 없다.**

**보험사 동향:** KB·신한 등이 일본 SOMPO 벤치마킹. 검증된 외부 솔루션 도입이 자체 개발보다 빠르다는 판단.

### 8-2. 국내 직접·잠재 경쟁자

**동국대 × 시니스트 × 메디브케어랩:** 과기부 16.77억[^8]. 회상치료는 4개 치료법 중 1개. 스코프 과잉, 2028 타임라인. 위협: 공신력, 의료연계.

**딥브레인AI 리메모리:** 2024 매출 71.6억[^9]. 사후 데이터 모델. 생전 누적 대화 데이터 없고 요양시설 채널 부재. 위협: pivot 시 자본력. **시간 창 ~18개월.**

**케어포:** 14,000+ 기관[^12]. 행정 도구. 보완 관계 — 연동 파트너 후보.

**잠재 경쟁자:** 보험사 자체 개발(가장 현실적 위협) > 대형 IT(카카오, 네이버) > 대학 스핀오프 > 실버테크 pivot > 요양시설 체인 자체 개발.

**진짜 경쟁자는 무관심이다:** 직원 귀찮음, 보호자 무관심, 노인 컨디션, STT 실패, 현장 와이파이, 동의서 회수 지연, 원장의 "이거 없어도 시설은 돌아감". 이 현장 마찰이 대기업 경쟁보다 현실적 위협.

### 8-3. 해외 참고 사례

**Rendever + Nova (미국, VR 기반)[^13]:**
MIT AgeLab 스핀오프. 미국 대형 시니어 케어 사업자의 50%+가 VR 도입, Rendever가 주요 공급자. 2024~2025년 AI 컴패니언 "Nova" 출시 — AI 주도 대화 + 개인화 VR + 세션 내용 "Memory Box" 축적. **가족에게 transcript·녹음 접근권 제공.** NIH $4.5M 연구 자금. 교훈: (1) 정부 자금이 이 분야에 집중, (2) "가족 전달"이 글로벌 핵심 기능으로 부상, (3) VR 하드웨어 의존이 한계 — 우리는 태블릿으로 접근성 차별화.

**Remme (미국, 사진 기반 AI)[^14]:**
FaceTime형 인터페이스로 AI가 사진 기반 회상 대화 진행. 세션 후 케어팀에 대화 프롬프트·세션 요약 대시보드 제공. 2025년 시니어센터 피드백 수집 단계(GeekWire Startup Radar 보도). 우리와 가장 유사하지만 구술 깊이 얕고(사진 의존), 가족 검증 레이어 없음. 교훈: (1) 유사 서비스 동시다발 출현 — 시장 타이밍 확인, (2) 사진 vs 구술 접근이 데이터 깊이를 결정.

**Kodak Memory Shots (벨기에)[^15]:**
치매 환자 구술 기억을 AI가 코닥 카메라풍 사진으로 생성. 벨기에 치매 센터 70% 도입. Stable Diffusion XL 기반, 무료 오픈소스. **핵심 발견: AI 이미지 기반 대화가 일반 대화보다 훨씬 깊고 감정적이고 길어졌다.** 우리 AI 이미지 기능의 임상적 근거.

**StoryWorth (미국)[^16]:**
매주 질문 이메일 → 가족 답변 → 인쇄 책. 100만 권+ 발행, 직원 10명, bootstrapped. Basic $59/년, Unlimited $199/년. 교훈: B2C만으로는 VC scale 안 됨 — B2B 채널 필수.

**HereAfter AI / StoryFile (미국):** HereAfter는 사후 AI 단독 성장 정체. StoryFile은 $9.5M 투자 후 파산(전용 스튜디오 의존). 교훈: 사후 AI 단독 불가, 하드웨어 의존 모델 실패.

**こころみ「親の雑誌」(일본)[^18]:**
2015년 시작, 1,000건+ 신청, 700건+ 발행. 18만엔(~170만원), 전 5권 풀컬러. 하루 1건 발행 속도. 교훈: (1) 수요 검증됨, (2) 인간 인터뷰 = scale 한계 (14년간 700건). AI 전환이 핵심.

**TOPPAN WAN-かいご (일본)[^17]:**
2024.07 출시. AI가 이용자 상태별 레크리에이션 플랜 자동 생성. 500종+ 근거 기반 콘텐츠(도쿄대 공동 연구). 2025.07 재택 모니터링 추가. 교훈: (1) 요양시설 SaaS 일본에서 본격 형성, (2) 한국에 이 포지션 공백, (3) 대기업 참여 — 시장 규모 검증.

**SOMPO (일본)[^19]:** 일본 최대 손보사. 요양시설 직접 운영 + AI 돌봄 R&D 수천억. 보험사 요양 AI 투자 선례 — KB·신한 미래 행보 예측 근거.

## 10. 법무·윤리

### 동의 6단계

L1(참여·녹음) → L2(가족 전달) → L3(상품화) → L4(사후 열람) → L5(비식별 연구) → L6(비식별 외부 라이선싱). 각 독립 opt-in. 구두 설명 + 서면 병행.

### 핵심 원칙

노인 본인 의사 최우선. 민감 기억 4단계 분류(일반→주의→민감→위기). 삭제 SLA: 철회 24h 차단 → 7일 삭제. 라이선싱 시 보험 심사·개인 프로파일링·광고 타깃팅 사용 절대 금지.

### 윤리 = 진입장벽

고령자 감정 대화 데이터는 아무나 수집할 수 없다. 적법한 동의, 노인 친화 설명(16pt+, 구두·녹음 병행), 철회권, 비식별, 민감정보 프로토콜 — **이 절차가 후발주자의 진입장벽.** 윤리는 비용이 아니라 해자.

### AI 기본법 대응

고위험 AI 해당 여부 법률 자문 (D-30 필수). AI 표시 의무 반영 완료. 의료기기 비해당 입증 (복지 프로그램).

### 보험사 레드라인

(1) 데이터 권리 본사 보유 (2) 비전속 (3) 사용 제한 — 언더라이팅·보험료 산정 불가. 제공 범위: 집계 통계, 효과 리포트, engagement 인사이트, 시설 만족도 지표.
